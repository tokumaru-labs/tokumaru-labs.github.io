Arcade Counter Timer

Chrome Extension · version 0.3.0 · Tokumaru Labs

A count-up timer and tally counter for Chrome. Use it in a toolbar popup, a draggable floating panel, or Chrome's side panel, with brief arcade-style feedback at milestones.

邪魔をしないカウントアップタイマーとタリーカウンター。節目にだけ、ほんの一瞬アーケードになります。

The image above shows an earlier version. See the Chrome Web Store screenshots for the 0.3.0 themes.

Key features

  • Count-up timer in HH:MM:SS that keeps running while the popup is closed and across browser restarts.
  • A tally counter — one press, one count — with its own reset.
  • Local TODAY / WEEK / MONTH / YEAR statistics.
  • Brief milestone feedback: fly text on fast streaks and a CHAIN burst every 10th count.
  • Original sound effects generated with the Web Audio API — no audio files.
  • Every effect (sound, fly text, chain, CRT scanlines) can be switched off. Works entirely offline.

New in 0.3.0

  • Six themes: Space Age, Arcade, Editorial, Steampunk, Art Deco and Nixie. Every theme shares the same timer, counter and records. An existing Original preference becomes Space Age. Images and fonts are bundled for offline use.
  • Repeatable COUNT undo: press UNDO to remove retained COUNT operations in reverse order. History survives closing a view or restarting Chrome and is shared across popup, floating and side-panel views. Each undo corrects the count's original day's statistics, even after midnight, without rewinding the timer.

Timer, count, session and full-data resets clear undo history. Start/stop and theme changes keep it. A valid older single undo step can carry forward, but past operations cannot be reconstructed from totals.

Privacy

  • Works entirely offline with no account and no network communication.
  • Timer state, counts, undo history, statistics and settings are kept locally on your device.
  • No analytics, no tracking, and no ads.

完全オフラインで動作し、アカウント不要。タイマーと統計は端末内にのみ保存し、分析・トラッキング・広告はありません。

Free to install and use. Normal updates with the same extension ID retain records and settings. Update the existing extension: uninstalling it removes local data.
