TOKU CONTROL

デスクトップに、
小さな操作室を。

Windowsアプリ · v0.2.1 · 無料

音量・液晶時計・メーター・Windowsのシステム情報を、90年代風のローカル操作盤に。青いタイトルバーと緑の数字で、いつもの操作をまとめます。

Windows版をダウンロード起動までの3ステップ

Windows x64 · ZIP / 64.4 MB · .NET同梱 · Windows 11で検証

初期公開版のためコード署名はありません。Windowsに発行元不明と表示される場合があります。信頼できる配布元から取得してください。インストーラー・アカウント・管理者権限は不要です。

いつもの操作を、ひとつの場所に

  • 再生音量と出力先：音量・ミュートを調整し、選んだ再生出力へ切り替えます。対応機器ではピークをL/Rで表示します。
  • 液晶デジタル時計：太い時・分と小さな秒、日付、25/50分の無音タイマー。
  • PCとモニター情報：CPU・RAMの履歴、ドライブ容量使用率、Windows・機器の情報、使用中モニターの解像度・Hz・拡大率など。
  • 一緒に動く小窓：SHOW ALLでメイン右に3つの小窓を縦積み。メインのタイトルバーをつかむと、表示中の小窓も一緒に動きます。
  • 調整できるCRT表現：走査線・発光・色ずれ・ノイズ・減光を即時調整。RAWで効果をOFFにできます。

ダウンロードして、起動する

  1. Windows版ZIPを取得上のダウンロードボタンから取得できます。リリースページには、照合用のSHA-256チェックサムとソースコードもあります。
  2. ZIPをすべて展開DLLやライセンスファイルも同じフォルダーに保持してください。EXEだけを別の場所へ移すと起動できません。
  3. TokuControl.exeを起動SHOW ALLで小窓を整列。出力先は選択後にSET OUTPUTで切り替えます。メインの×で全体を終了します。

使う前に知っておきたいこと

  • 標準配置は全体で約1512×848論理ピクセル。Windowsの拡大率により必要な物理サイズが変わり、メインの横幅は縮められます。画面に収まらない場合は小窓を個別に使えます。
  • 出力切替は通常再生用の既定出力が対象です。マイク・通話用・アプリ別の出力設定は変更しません。Windowsの非公開インターフェースを使用するため、更新や環境によって互換性が変わる場合があります。
  • メーターは再生ピークの表示で、アプリ別ミキサーや周波数スペクトラムではありません。DISK USEDは容量使用率です。
  • 光学ドライブのトレイを閉じる操作は機種依存です。倍率の異なるモニター間の移動や、Windowsのスナップ・最大化を伴うドラッグは十分な検証ができていません。

ローカル保存とソースコード

アカウント・遠隔操作サーバー・アプリ独自の解析通信はありません。設定は端末内の %LOCALAPPDATA%\TokumaruLabs\TokuControl\settings.json に保存します。ログはSAVEを選んだ時だけ書き出します。Windows/.NETのエラー報告はOS設定と提供元の条件に従います。

Windowsに反映した音量・ミュート・出力先は、アプリを終了しても維持されます。見た目と位置を初期化するには、終了後にsettings.jsonを別の場所へ移してください。アプリの削除は終了後に展開フォルダーを削除します。
