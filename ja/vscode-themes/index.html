Tokumaru Labs VS Code Themes

無料のカラーテーマ3種セット · v0.1.0

秘密基地のような深い濃紺、昼間の作業でも読みやすい明色、静かなレーダーグリーン。3テーマを1つのVS Code拡張で切り替えられます。

VSIXをダウンロード (v0.1.0)GitHub SourceMatching Chrome Theme

上の画像は実機スクリーンショットではなく、テーマ配色に基づくモックアップです。構文色は言語や導入済み拡張によって異なる場合があります。

インストール方法

  1. 上のボタンから .vsix を保存する。
  2. VS Codeの拡張機能 → … → VSIXからインストールを選び、保存したファイルを指定する。
  3. 基本設定：配色テーマ（Windows/Linux: Ctrl+K Ctrl+T、Mac: Cmd+K Cmd+T）から好きなテーマを選ぶ。

コマンドからも導入可能：code --install-extension tokumaru-vscode-themes-0.1.0.vsix。VSIX経由の導入は原則として自動更新されません。

テーマの特徴

  • 各テーマ149項目のUI配色。ターミナル・サイドバー・エディタ・タブなどを統一。
  • キーワード・文字列・コメントなどの構文色とセマンティックハイライト。
  • 実行スクリプト・通信権限・アクセス解析・トラッキング・追加フォントは不要。
