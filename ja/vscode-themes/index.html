TOKUMARU LABS VS CODE THEMES

Tokumaru Daylight

夏の午後を、コードのそばに。

薄青い空、海の青緑、雲の紫。太陽の金色とローズを少し添えた、夏の午後を思わせるライトテーマ。コードはくっきり、色は静かに。

無料・MITライセンス · 3テーマをひとつに

MarketplaceでインストールVSIXを保存 (v0.2.1)GitHubのソース

3つの世界、ひとつの拡張

Daylightの夏の午後、Midnightの深夜のネオン、Radar Greenの静かなレーダー室。ひとつの拡張機能から切り替えられます。

インストール

  1. MarketplaceのページからInstallを選ぶ。VS Codeの拡張機能でTokumaru Labs VS Code Themesを検索しても導入できます。
  2. 基本設定：配色テーマを開く。Windows/LinuxはCtrl+K Ctrl+T、MacはCmd+K Cmd+T。
  3. Tokumaru Daylightを選ぶ。MidnightとRadar Greenも同じメニューから切り替えられます。

コマンドからも導入できます： code --install-extension tokumarulabs.tokumaru-vscode-themes

手動で導入する場合は、上のボタンからVSIXを保存し、VS Codeの拡張機能 → … → VSIXからインストールでファイルを選びます。VSIXからの導入は原則として自動更新されません。

テーマの特徴

  • エディター、タブ、サイドバー、ステータスバー、ターミナルの配色を統一。
  • 構文の色分けとセマンティックハイライト。表示は言語や導入済み拡張によって変わります。
  • 配色データのみ。実行スクリプト、フォントの強制、アクセス解析、通信処理は含みません。
