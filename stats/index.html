この数字で分かること・分からないこと
  • GitHub Releasesの配布ファイルごとの回数です。サイト経由以外の取得、同じ人の再取得、動作確認分も含み得ます。人数・インストール数・保存完了の保証を表す数字ではありません。
  • Chromeウェブストア、VS Code Marketplace、サイト内の予備ファイルからの取得は含みません。VSIXの過去の直接配布分も遡って数えません。
  • 増分は2回の観測の差です。深夜0時ちょうどで区切った日別件数ではありません。取得失敗や記録のない日は0回とみなさず、次の成功時に複数日分の区間として表示します。
  • 初回記録は比較の基準です。ファイルの削除・入替・カウンターの減少で比較できない区間は「比較不可」と表示します。
  • 通常ZIPの集計条件と過去の履歴は継続します。参考指標の観測開始前は「未記録」で、0回にはしません。参考指標の初回取得値も比較の基準です。CSVでは指標ID・通常配布／参考の区分・説明を末尾の列に記載します。
  • 記録は毎日00:17ごろに取得予定です。実行が遅れることもあります。2日以上更新されない場合はページ上に表示します。

通常メニューや検索には掲載しませんが、認証はありません。このページと集計データはURLを知っていれば閲覧できます。訪問者の個人情報やクリック履歴は収集しません。
