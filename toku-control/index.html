for your desktop.

Your everyday controls, in one place

  • Playback audio: adjust volume, mute, and explicitly switch the default playback output. The peak meter shows L/R where the device supports it.
  • LCD clock: bold hours and minutes, small seconds, the date, and silent 25/50-minute timers.
  • System and displays: CPU/RAM history, drive capacity use, Windows and hardware details, and active monitor resolution, refresh rate and scale.
  • Small windows that move together: SHOW ALL stacks the three modules beside the main window. Drag the main title bar to move visible modules with it.
  • Quick Launch (v0.2.2): open Task Manager, all classic Control Panel items, Task Scheduler and Startup Apps settings directly.
  • CRT character: adjust scanlines, bloom, RGB edge, noise and vignette live. RAW turns the effects off.

Download, extract, start

  1. Download the Windows ZIPUse the download button above. The release also includes a SHA-256 checksum and matching application source.
  2. Extract the entire ZIPKeep all DLLs and license files in the extracted folder. Running only the EXE copied elsewhere will not work.
  3. Run TokuControl.exeUse SHOW ALL to arrange the modules. Select an audio output, then press SET OUTPUT to change it. Closing the main window closes the application.

A few things to know

  • The standard full arrangement is about 1512 × 848 logical pixels. Windows scaling affects the physical space needed; the main window can shrink in width. If there is not enough room, use modules individually.
  • Output switching changes the regular playback defaults, not the microphone, Communications default or per-app output overrides. It uses an undocumented Windows interface, so compatibility may change with Windows updates.
  • The audio meter is a peak meter, not a per-app mixer or a spectrum analyzer. DISK USED is storage capacity use, not disk activity.
  • Optical-drive tray closing depends on the hardware. Mixed-DPI monitor moves and Windows snap/maximize dragging have not been exhaustively tested.

Local settings and source

The application has no accounts, remote-control server or application analytics. Its settings stay in %LOCALAPPDATA%\TokumaruLabs\TokuControl\settings.json. Logs are exported only when you choose SAVE. Windows/.NET error reporting follows your OS settings and vendor terms.

Volume, mute and default-output changes remain in Windows after the app exits. To reset appearance and positions, exit and move settings.json aside. To remove the app, exit and remove the extracted folder.
