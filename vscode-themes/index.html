Three worlds, one extension

A summer afternoon in Daylight, Citypop midnight neon, and a quiet phosphor-green terminal. Switch between all three from one extension.

Install

  1. Select Install on the Marketplace page, or search for Tokumaru Labs VS Code Themes in VS Code's Extensions view.
  2. Open Preferences: Color Theme: Ctrl+K Ctrl+T on Windows/Linux, or Cmd+K Cmd+T on Mac.
  3. Choose Tokumaru Daylight. Midnight and Radar Green are available in the same menu.

You can also install from the command line: code --install-extension tokumarulabs.tokumaru-vscode-themes

For a manual installation, download the VSIX above and select it from Extensions → ... → Install from VSIX... in VS Code. Direct VSIX installs do not receive automatic updates by default.

Included

  • Editor, tabs, sidebar, status bar, terminal and workbench colors.
  • TextMate syntax and semantic highlighting. Results vary with language support and installed extensions.
  • Pure color definitions: no runtime scripts, forced fonts, telemetry or network requests.
