Tokumaru Labs VS Code Themes

Color theme collection · 3 themes · v0.1.0 · Free and open source

A quiet workspace, with a little secret-base character. Choose deep-navy Midnight, clear Daylight or subtle Radar Green. All three come in one extension.

Download VSIX (v0.1.0)GitHub SourceMatching Chrome Theme

These are illustrated mockups using theme palette colors, not screenshots of running VS Code. Exact syntax colors may vary by language and extensions.

Install

  1. Download the .vsix above.
  2. In VS Code, open Extensions → ... → Install from VSIX... and choose the file.
  3. Open Preferences: Color Theme (Ctrl+K Ctrl+T or Cmd+K Cmd+T on Mac) to select one of the three themes.

Command-line option: code --install-extension tokumaru-vscode-themes-0.1.0.vsix. VSIX installs do not receive automatic updates by default.

Included

  • 149 UI colors per theme: editor, tabs, Explorer, status bar and terminal.
  • TextMate syntax and semantic token color definitions.
  • Pure color definitions — no scripts, permissions, forced fonts, telemetry or network requests.

Open source & distribution

Source code and MIT license are available on GitHub. This is currently a direct-download VSIX release; we do not claim it is listed on the Visual Studio Marketplace. Questions & feedback.
